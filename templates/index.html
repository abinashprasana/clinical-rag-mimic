Processing architecture

From question to reviewable response

Each stage exposes only what the current response contract can support. No claim-level citation mapping is inferred.

  1. 01

    Route

    Classify the request as record retrieval, FDA label lookup, clarification, or direct handling.

  2. 02

    Retrieve

    Search section-aware chunks and return the configured number of relevant passages.

  3. 03

    Generate

    Compose an answer locally from the retrieved context within model input limits.

  4. 04

    Check support

    Compare content words and numeric claims against the retrieved text; retry or refuse when gaps remain.

  5. 05

    Review

    Present the response with source passages, provenance identifiers, and limitations.

Known boundaries

What the system does not establish

Data and retrieval

  • The indexed sample does not cover the complete MIMIC-IV-Note corpus.
  • Retrieval relevance ranks text similarity, not clinical importance or correctness.
  • Answers can omit relevant facts outside the retrieved passages.

Generation and support check

  • The generator is general-purpose and may paraphrase, omit, or misstate information.
  • The source-support check uses content-word and numeric overlap, not clinical verification.
  • Evaluation uses a small structural question set and rigid keyword matching.
